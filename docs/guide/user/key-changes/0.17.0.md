# 0.17.0

## 変更点

ここでは主要な変更を紹介します。全ての変更点については[CHANGELOG.md]をご覧ください。

### ONNX Runtime 1.23対応

推奨されるONNX Runtimeのバージョンが1.17.3から1.23.2に上がりました。`Onnxruntime::load_once`がデフォルトで探すVOICEVOX ONNX Runtimeの動的ライブラリも1.23.2のものになります。バージョン1.17.3も引き続き利用できます。

またCUDAにおいて、ONNX Runtime 1.23以降のCUDAでも[それなりのパフォーマンスを保てる](https://github.com/VOICEVOX/voicevox_core/issues/1391#issuecomment-5121934874)ように設定を変えました。

[Release voicevox_onnxruntime-1.23.2 · VOICEVOX/onnxruntime-builder](https://github.com/VOICEVOX/onnxruntime-builder/releases/tag/voicevox_onnxruntime-1.23.2)

### 新形式VVM（`vvm_format_version=2`）への対応と`StyleType::StreamingTalk`

新しい形式のVVMを利用できるようになり、`StyleType`に`StreamingTalk`タイプが追加されました。`StreamingTalk`の機能は現時点では`Talk`と同じです。`StreamingTalk`に特有の機能は[今後実装される予定](https://github.com/VOICEVOX/voicevox_core/issues/1364)です。

新形式のVVMは次のようにすれば判別できます。

```console
❯ unzip -p ./path/to/vvm manifest.json | jq .vvm_format_version
2
```

新形式のVVMは以下からダウンロードできます。

[Release 0.17.0 · VOICEVOX/voicevox_vvm](https://github.com/VOICEVOX/voicevox_vvm/releases/tag/0.17.0)

ダウンローダーを使う場合は次のようにします。

```console
❯ ./path/to/download --only models --models-version 0.17.0
```

### XCFrameworkのmacOS対応

リリースされるXCFrameworkにmacOS向けのライブラリが同梱されるようになりました。それに伴いファイル名はvoicevox\_core-xcframework-{バージョン}.zipという形になりました。

### macOSバイナリへの署名

リリースされるmacOS版動的ライブラリのlibvoicevox\_core.dylibがコード署名されるようになりました。

### `on_existing`オプション

`Synthesizer::load_voice_model`に`on_existing`オプションが追加されました。`Reload`を指定して再ロードすることで、占有されていたメモリが解放されることがあります。

```py
with VoiceModelFile("./path/to/vvm") as vvm:
    synth.load_voice_model(vvm)
    synth.load_voice_model(vvm, on_existing="RELOAD")  # 再ロード
```
