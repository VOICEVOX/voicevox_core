### ストリーミングトーク機能

音声を少しずつ生成できるようになりました。十分な性能のGPUかCPUがあれば、音声合成の開始からコンマ数秒後に音声再生を始められます。

```py
synth: voicevox_core.asyncio.Synthesizer
query: voicevox_core.AudioQuery
STYLE_ID: voicevox_core.StyleId

stream = await synth.streaming_synthesis(query, STYLE_ID)

_wav_header = await anext(stream)
async for pcm in stream:  # デフォルトで28フレーム ≒ 0.3秒ずつ生成
    ...
```

```py
# 音声合成の区切り方を細かく制御したい場合

from voicevox_core import FRAME_RATE

feat = synth.create_audio_feature(query, STYLE_ID)

SEGMENT_LENGTH = round(0.3 * FRAME_RATE)
for ofs in range(0, query.frame_length(), SEGMENT_LENGTH):
    pcm = synth.render(feat[ofs:][:SEGMENT_LENGTH])
    ...
```

NOTE: ↑のコードは#1454が前提

### `AudioQuery::frame_length`と`FRAME_RATE=93.75`

`AudioQuery`から音声の長さを見積れるようになりました。ストリーミングトーク機能と合わせて是非御活用ください。

```pycon
>>> synth: voicevox_core.blocking.Synthesizer
>>>
>>> from voicevox_core import FRAME_RATE
>>>
>>> FRAME_RATE  # フレーム数/秒
93.75
>>>
>>> TEXT = "こんにちは、四国めたんです"
>>> STYLE_ID = 0  # 四国めたん（あまあま）
>>> query = synth.create_audio_query(TEXT, STYLE_ID)
>>> query.frame_length()  # フレーム数
213
>>> query.frame_length() / FRAME_RATE  # 秒
2.272
```

### \[C\] `voicevox_json_free`と`voicevox_wav_free`の改名

`voicevox_json_free`は<code>voicevox\_**string**\_free</code>に、`voicevox_wav_free`は<code>voicevox\_**bytes**\_free</code>に改名されました。本バージョンの時点では古い名前の関数も`[[deprecated]]`なものとして引き続き利用可能です。

また本バージョンで追加される`voicevox_synthesizer_render`は、空の範囲を入力すると空のバイト列として`const uint8_t *voicevox_empty_bytes`を返します。`voicevox_empty_bytes`を`voicevox_bytes_free`に渡すことは推奨されません。クラッシュはしませんが、警告は出るようになっています。
