# 0.17.1

## 変更点

ここでは主要な変更を紹介します。全ての変更点については[CHANGELOG.md]をご覧ください。

### ストリーミングトーク機能

音声を少しずつ生成できるようになりました。十分な性能のCPUやGPUがあれば、音声合成の開始からコンマ数秒後に音声再生を始められます。

```py
# この`stream`の作成は一瞬。
stream = await synthesizer.streaming_synthesis(query, style_id)

# 最初の要素はWAVの先頭部分で、音声波形本体の手前まで。
_wav_header = await anext(stream)

# 少しずつ音声合成。デフォルトでは28フレーム（約0.3秒）ずつ生成。
async for pcm in stream:
    ...
```

```py
# 音声合成の区切り方を細かく制御したい場合

from voicevox_core import FRAME_RATE

# この`feature`の作成も一瞬。
feature = await synthesizer.create_audio_feature(query, style_id)

# 少しずつ音声合成。
SEGMENT_LENGTH = round(0.3 * FRAME_RATE)  # 約0.3秒
for offset in range(0, len(feature), SEGMENT_LENGTH):
    pcm = await synthesizer.render(feature[offset:][:SEGMENT_LENGTH])
    ...
```

新形式（`vvm_format_version=2`）のVVMが必要です。[voicevox_vvm]の最新版をご利用ください。ダウンローダーはデフォルトで最新のVVMを取得するようになっています。

Java APIとC APIでは`streaming_synthesis`は未実装となっています。ただし`streaming_synthesis`は`create_audio_feature`と`render`のラッパーなので、それらを使うことでストリーミング音声合成は可能です。

### `AudioQuery::frame_length`と`FRAME_RATE=93.75`

`AudioQuery`から音声の長さを見積れるようになりました。ストリーミングトーク機能と合わせてぜひご活用ください。

```pycon
>>> synth: voicevox_core.blocking.Synthesizer
>>>
>>> from voicevox_core import FRAME_RATE
>>>
>>> FRAME_RATE  # 単位：フレーム数/秒
93.75
>>>
>>> TEXT = "こんにちは、四国めたんです"
>>> STYLE_ID = 0  # 四国めたん（あまあま）
>>> query = synth.create_audio_query(TEXT, STYLE_ID)
>>> query.frame_length()  # 単位：フレーム数
213
>>> query.frame_length() / FRAME_RATE  # 単位：秒
2.272
```

### \[C\] `voicevox_json_free`と`voicevox_wav_free`の改名

`voicevox_json_free`は<code>voicevox\_**string**\_free</code>に、`voicevox_wav_free`は<code>voicevox\_**bytes**\_free</code>に改名されました。本バージョンの時点では古い名前の関数も`[[deprecated]]`として引き続き利用できます。

また本バージョンで追加される`voicevox_synthesizer_render`は、空の範囲を入力すると空のバイト列として`const uint8_t *voicevox_empty_bytes`を返します。`voicevox_empty_bytes`を`voicevox_bytes_free`に渡すことは推奨されません。クラッシュはしませんが、警告は出るようになっています。
